# Bike Sharing Demand Analysis | Excel Dashboard

## Project Overview
This project analyzes bike rental demand using Microsoft Excel to identify rental patterns, weather impacts, user behavior, and operational insights.

## Tools & Techniques
- Microsoft Excel and Power Query
- Data Cleaning and Validation
- PivotTables, PivotCharts, and Calculated Fields
- Interactive Dashboard with Slicers and Timeline
- VBA Macros for Refresh and Reset Filters
- Forecasting using FORECAST.LINEAR
- Outlier Detection using the IQR Method
- Weather-wise Funnel Chart

## Key Findings
- Total Bike Rentals: 58,304
- Average Hourly Rentals: 58.30
- Registered Users: 53,383 (91.6%)
- Casual Users: 4,921 (8.4%)
- Peak Rental Hour: 5 PM
- Clear/Fair Weather Rentals: 37,373 (64.1%)
- 30 high-demand outliers identified using IQR

## Dashboard Features
The dashboard includes rental demand trends, hourly demand analysis, weather comparisons, user distribution, a 7-day statistical forecast, interactive slicers, a date timeline, and VBA automation.

## How to Use
1. Download the Bike_Rental_Demand_Insights.xlsm file.
2. Open it in desktop Microsoft Excel.
3. Enable macros only if you trust the workbook.
4. Use the slicers and timeline to explore rental patterns.
5. Use the dashboard buttons to refresh data or reset filters.

## Note
Forecasting uses Excel's FORECAST.LINEAR function, and anomaly detection uses the statistical IQR method. These are not AI-based models.
